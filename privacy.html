プライバシーポリシー

最終更新日: 2026年11月19日

対象

このポリシーは OpenClaw Drive(以下「本ツール」)に適用されます。本ツールは運営者が個人で使う作業自動化ツールで、 一般には提供していません。Google アカウントで本ツールを認可できるのは、運営者のチームが共有するアカウントだけです。

アクセスするデータ

本ツールは、認可された Google アカウントのドライブ上のファイルとそのメタデータ(名前、種類、更新日時、フォルダ)に、 Google Drive API を通じてアクセスします。アクセスは、運営者の Slack ワークスペースで依頼された作業(検索、読み取り、 作成、本文の更新、名前の変更と移動、ゴミ箱への移動)を行うときに限られます。共有設定の変更と完全削除は行いません。

データの使い方と保存

  • 取得したファイルの内容は、依頼された作業の結果として、依頼元の Slack ワークスペースに返すためだけに使います。
  • 処理の過程で、ファイルの内容は AI モデルの提供者(OpenAI)に送られることがあります。
  • 認可に使うトークンは、運営者が管理するサーバーにだけ保存し、第三者に提供しません。
  • Google ユーザーデータを広告、販売、または AI モデルの学習のために使うことはありません。

本ツールによる Google API から受け取った情報の使用と他のアプリへの転送は、 Google API Services User Data Policy (Limited Use の要件を含む)に従います。

認可の取り消し

認可は、Google アカウントの「サードパーティ製のアプリとサービス」 (https://myaccount.google.com/connections)からいつでも取り消せます。

Privacy Policy (English)

OpenClaw Drive is a personal automation tool operated for a single team and is not offered to the public. Only a Google account shared by the operator's team authorizes it.

It accesses files and file metadata in the authorized Google Drive through the Google Drive API, only to carry out tasks requested in the operator's own Slack workspace (search, read, create, update content, rename and move, move to trash). It does not change sharing settings and does not permanently delete files.

File contents are used only to return results to that Slack workspace and may be processed by the AI model provider (OpenAI) while doing so. Authorization tokens are stored only on a server the operator controls and are not shared with third parties. Google user data is never used for advertising, sold, or used to train AI models. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at https://myaccount.google.com/connections. Contact: GitHub Issues.
